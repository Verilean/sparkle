## 2. The command and its scope

`#machine_no_ports_memseq f` — an error where it is refused or fails.
`#machine_no_ports_memseq_try f "EXPECTED"` — the outcome is logged
(`NOPORTS MEMSEQ f: GENERATED | REBUILT | REFUSED (reason) | FAILED (condition)`), an error when its class is
not the expected one; a refused / failed declaration leaves nothing (environment and messages put back).

Scope: a machine with `machineData / machine_ok / machine_body`, the base `f.machine_ships_hierR` and
`f.machine_design_svR0` (`#machine_design_svR0`), at least one register slot, the general closing, whose call
entries are of ≥ 1 leaf register machine (register, no call, `c.machine_closes`; any number of different ones)
AND ≥ 1 memory placeholder (either read kind, any number of different ones, each with its own `(aw, dw)`).
Depth 0, at-form closing only.

Generated, in this order (lemmas under `f.noPortsMemSeq_*`; the two endpoints under the hand names):

    [c.machine_leafKid        per distinct leaf callee: USED when present (statement checked by isDefEq),
                              generated by the built leafKidTheorem when absent]
    f.noPortsMemSeq_{outsOf,insOf,nameOf,nkOf,outsNOf,namesOf}     tables keyed by the CALLEE (nested ifs)
    f.noPortsMemSeq_{table}_at{i}                                  the table at key i (leaves first, then placeholders)
    f.noPortsMemSeq_entry      ONE decided ∀ over the reader's entries: callee = one of the keys
    f.noPortsMemSeq_calls / _slots / _domB / _outTy / _callWidths / _callArgs / _outChars / _outScalar
    f.noPortsMemSeq_kids       KidFactsM per entry, depth 0 (leaf: leafKid_facts + kidFacts_toM; placeholder: memKid_facts)
    f.noPortsMemSeq_runFacts / _outsG0 / _mixedG / _designP0       kidsM_* at f's data
    f.machine_design_noPortsR0
    f.noPortsMemSeq_alias / _argsN / _fieldOut / _fieldsNd / _outHead
    f.noPortsMemSeq_notinP{j} / _leafNotin{i}_{j} / _leafNeParent{i} / _leafNe{i}_{j} / _memNe{i}_{j}
    f.noPortsMemSeq_iface{i}   ChildIfaceP of leaf i's real child (seqChild_of_real, .toD, .toP)
    f.noPortsMemSeq_kidsP / _sep / _parent / _parentD / _disj
    f.noPortsMemSeq_closes     machineClosesAt_of_kidsDM; premises: MachineDefines of each DISTINCT leaf callee only
    f.machine_design_noPortsR0_closed

then the premise lines of both endpoints, with the command's own assertions: exactly one NOT ALLOWED in the
open endpoint, none in the closed one; the closed one has one line fewer plus one per leaf callee;
`f.noPortsMemSeq_closes` has exactly the leaf callees' reflections as proposition premises; no statement
mentions a checker constant; the closed one no `MachineCloses` / `MachineClosesAt` / `ChildRanIn`.
`…_closed_gap` is NOT made by the command (`#machine_goal_gap_of`).

Compare path: for every name of `f.*` the command would add, if it exists it is rebuilt, added as `…_regen`
and compared by `isDefEq` (a theorem's statement; a table's value) — an error otherwise.
`c.machine_leafKid` is the CALLEE's: checked and used, never re-added (two parents of one callee in one import
closure would clash on `c.machine_leafKid_regen`).
