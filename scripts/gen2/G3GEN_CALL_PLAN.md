# G3-GEN-CALL: dependency and acceptance plan (proposal for review; nothing applied)

Requested by the approval of `sparkle-gen2-calldec` (evidence head 5c1b78a1). Until this plan is approved:
- G-CALLDEC stays UNSUPPLIED in general;
- M2's text is unchanged;
- `T1Hyp.dec` and `CallDec` are unchanged.

## 1. The exact obligation
For the generated package `p` of every accepted machine-route declaration `X` (`P X = some p`), and every call `k` with
`(origin k).child? = none` to a callee `c = (insts[k]).1` with `P c = some q`:

```
GenCallStmt L P Reach :=
  ∀ X, Reach X → ∀ p, P X = some p → ∀ k (hk : k < p.d.shape.insts.length),
    (p.d.shape.instOrigins.getD k .ord).child? = none → ∃ q, P (p.d.shape.insts[k]).1 = some q ∧
    -- the complete per-call statement (never its decoding half alone)
    HPointAt p.d p.kD dom p.lsrc p.extS p.extBS (pkgOutsC P) (pkgBsC P) (pkgSrc P) k ∧
    -- the call-pair data of callDec_of_callFactF
    callArgsOk p.d p.kD (fun k => argWidths of (insts[k]).1's package) = true ∧ hlen-row at k
```

With `callDec_of_callFactF` and `callFactF_of_hPointAt_pkg` (both proved), `GenCallStmt` yields `T1Hyp.dec`'s ordinary
disjunct for every reached declaration. Its scope is ORDINARY calls only. Memory calls are `MemDec` (G-MEMCALLS, M2-a).

## 3. Deliverables and placement
- **G3-GEN-CALL-a (t1, t3):** generator lemmas: the generated `machineExt`/`machineSource` equal the call-term
  extension and the declaration's outputs. M5 (G3-GEN), after G3-SHAPE, because it needs the reader's call reading tied
  to `d.shape`.
- **G3-GEN-CALL-b (t2):** a lemma from `body_eq` and the reader's call entries to "arguments = let observations". M5.
  This is the main proof.
- **G-DATA-CALL (`hargs`, `hlen`):** from the successful run's instance closing. M3, next to G-SERVED, because it is a
  fact of the run (ports connected in the emitted design), not of the generator.
- **`hw`:** proved in M2-b, as a one-line generic lemma.
- **The conclusion:** `GenCallStmt`. Once (a), (b) and G-DATA-CALL hold, `T1Hyp.dec`'s ordinary half is removed from
  `T1Stmt`'s premises (an amendment, reviewed then).

## 4. Acceptance
- Each part is a theorem over all packages / runs, with no per-design binder.
- The checks: the C4/C5 parents and `topshare2` are recovered with no use of their `CallFactF`/`b_*_hFP` theorems
  (closure audit).
- M5 completion requires `GenCallStmt`. A partial result (for example t1 and t3 only) is not completion.

## 5. Failure routes (evaluated separately before any user decision)
- **If t2 cannot be stated from `body_eq` and the reader:** a generator-exported, kernel-checked theorem of uniform
  statement, emitted for every declaration. Cases:
  - (a) Every successful compilation provably comes with it, connected to the same source and result. Then it is
    existential evidence eliminated inside FG, and the guarantee does not change.
  - (b) Its availability is an unproved premise. That is a guarantee change, for the user.
  - (c) The accepted sources are restricted to those with it. That is a scope change, for the user.
- **If G-DATA-CALL fails for some successful run** (a width mismatch the closing accepts): that is a counterexample to
  the row, not to FG. Plan a consumer that uses the closing's actual port widths; a scope change only via the user.
